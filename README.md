# BlogSpace — Responsive Blog Application

A responsive blogging application built using HTML, CSS,
and JavaScript.

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Pages

1. Home
2. Login
3. Register
4. Dashboard
5. Create Blog

## Features

- Responsive design
- User registration and login demo
- Form validation
- Blog creation and publishing
- Save drafts
- Search blog posts
- Filter by category
- Dashboard statistics
- Delete blog posts
- Browser LocalStorage persistence

## Installation

1. Download or clone the project.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser.
4. Alternatively, use the Live Server extension.
5. Register an account and start writing blogs.

## Important Security Note

This project is for learning frontend development.

It stores demo account information in LocalStorage.
Passwords are not securely hashed, and client-side
authentication is not suitable for production.

A real application should use server-side authentication,
secure password hashing, authorization, and a database.
